# 던전 서바이버즈

몰려오는 마물을 자동 공격으로 쓸어버리며 50층의 탑을 오르는 픽셀 판타지 서바이벌 게임 (Vampire Survivors 스타일, 단일 HTML).

▶ 플레이: https://jkspawn.github.io/pixelsurvivor/

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (모바일: 화면 드래그) |
| 1 ~ 4 | 레벨업 보상 선택 |
| ESC / P | 일시정지 |
| M | 소리 끄기 |

## 영웅 (8명)
바바리안 · 마법사 · 기사 · 암살자 · 무도가 · 궁수 · 저격수 · 성녀 — 각자 고유 시작 무기와 능력치를 가집니다.

## 진행
- 한 층은 30초. 층이 오를수록 몬스터가 강해지고 새로운 종류가 등장합니다 (몬스터 10종).
- **10층마다 보스 출현**: 오우거 킹 → 리치 군주 → 홍염룡 → 흡혈귀 여왕 → 마왕. 보스를 쓰러뜨리면 보물 상자(강화 3개)를 얻습니다.
- 50층 마왕을 쓰러뜨리면 탑 정복! 이후 무한 모드로 계속할 수 있습니다.
- 무기 12종 · 패시브 11종, 무기 최대 6개 / 패시브 최대 6개.
